# Lingo project pro
Lingo project pro is my full-stack project which I am developing to help my fiance in her work.
Also it will help me improve mine coding skills and make me a good working project on portfolio.

The core of the project is managing the track of the workflow at her language office job.
The project will have management of projects for companies. What tasks she must do, or priority tasks.
Essentially it will be a jira like app.
